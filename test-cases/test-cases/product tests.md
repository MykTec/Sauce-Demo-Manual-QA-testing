# Product Test Cases

This document contains the manual test cases executed for the SauceDemo product functionality.

## TC-PRODUCT-002 — Product Information Display

**Test:** Check whether products display their basic information correctly.

**Expected Result:**
Each product should display an image, name, description, price, and Add to Cart control.

**Actual Result:**
The products displayed their images, names, descriptions, prices, and cart controls correctly.

**Status:** PASS

## TC-PRODUCT-003 — Sort Products by Name Z to A
